# Wealth Portfolio Tracker — Phase 0

Skeleton only. No domain models, no API, no agent logic. All placeholders in
`backend/core/services.py` and the `backend/agent/` package are importable but
raise `NotImplementedError` / return 501.

## Setup

Env files were generated by the scaffolding script. To rebuild from scratch:

    cp .env.example .env.base
    cp .env.example .env.dev
    cp .env.example .env.prod

Before any prod deploy, edit `.env.base` and `.env.prod`:
- `SECRET_KEY` — long random string
- `POSTGRES_PASSWORD` / `DB_PASSWORD` — strong and matching
- `ALLOWED_HOSTS` — your real domain(s)

## Dev

    docker compose up --build

- Backend (ASGI/Uvicorn): http://localhost:8000
- Frontend (Vite):        http://localhost:5173
- Django admin:           http://localhost:8000/admin/

`docker-compose.override.yml` is auto-loaded and applies: `build.target=dev`,
`:z` bind mounts, exposed ports.

## Prod

    docker compose -f docker-compose.yml -f docker-compose.prod.yml up --build -d

- Frontend (nginx): http://localhost:80
- Backend (Uvicorn `--workers 2`): http://localhost:8000

No code bind mounts in prod. `restart: unless-stopped` on both services.

## Notes

- Bind mounts carry `:z` for Fedora Silverblue / SELinux; ignored elsewhere.
- The backend **must** run under ASGI (Uvicorn). WSGI/Gunicorn will break the
  SSE agent endpoint in Phase 5.
- `django-cors-headers` is not installed yet — Phase 3 will add it when the
  SPA starts calling the API from a different origin.
